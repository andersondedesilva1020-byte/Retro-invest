# RETRO INVEST

## Simulador de Investimentos Online

O Retro Invest é um simulador de investimentos online gratuito.

Com ele você pode fazer simulações e entender como diferentes investimentos podem evoluir ao longo do tempo.

### 🚀 Acesse o simulador

https://retroinvest-oficial.netlify.app/

### 📊 Recursos

- Simulador de investimentos
- Simulação de rendimento
- Comparação de cenários
- Interface retrô
- Compatível com celular

### 💻 Projeto

Projeto independente desenvolvido para aprender programação e criar uma ferramenta útil.
